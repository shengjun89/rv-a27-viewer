# A27 R7 房车交互模型

在线预览：[房车完整演示](https://shengjun89.github.io/rv-a27-viewer/)。

同一份 FreeCAD R7 源文件导出几何与 15 项动作。包括洗衣机、冰箱、洗衣液柜门，以及既有办公、沙发、梯子、卷门和吊柜。电池改到沙发车外侧视图右半段，对应已有外舱门；白窗帘与现有装修模型保留。

## 使用

- 「播放全部」依次演示并复位；可暂停、继续或停止复位。动画保持相机，拖动可手动旋转观察。
- 柜门／电器门点击打开停住，再点关闭；快速重复点击不会叠加动作。
- 下拉框可选择单个部件；手机可收起操作区。顶部按钮提供视角复位、俯视、缩放和分享。
- 网页提供 R7 FreeCAD 模型与宏整包下载；解压后执行 `Macro/整车一键演示.FCMacro`。

网页加速播放：柜门 6 倍，其余 5 倍；完整播放约 22 秒。FreeCAD 原速约 113 秒，可选 0.5×／1×／2×。

当前为布局与动作演示：电池舱净口与整包更换路线待实车复尺；保留所有床架和排骨条，不从床面切检修口。电器铰轴以实物五金为准。

## 本地运行

需要 Node.js 22 及 Python 3。

```sh
npm ci
npm test
npm run build
npm run dev
```

打开 http://localhost:4173/ 。`main` 推送后 GitHub Actions 自动验证、构建并发布。资源均使用相对路径。

`src/` 为播放器；`public/rv-a27.glb` 为模型；`motion-data.json` 为 CAD 动作，`model-info.json` 记录版本与哈希。`test/fixtures/cad-checks.json` 核对铰轴和动作顺序。`scripts/export_scene.py` 在 FreeCAD 中运行，从当前打开的 R7 工程导出；只导出，不保存源模型。

[electrical.html](public/electrical.html) 包含中文单线图、回路与线径初选、功率预算、来源及待核项。用户提供48V/8kWh、5400W/40A，并确认直流充电桩取电器输出220V交流接一体机；用户进一步确认40A为充电限流，计量侧（电池侧/交流侧）及设定方式仍待铭牌确认。两路交流经先断后合互锁择一，禁止并接。淘宝读取仅得到登录页，未核实商品手册。

独立操作面板按用户第二张商品图补外形，四键/状态灯/显示屏为展示，无实时数据或实际控制。200×110×25mm是未获尺寸的占位，候选中心[-.15,1.67,.870]m（办公桌靠墙左侧）。商品图标注8米标准网线延长，但不据此当成普通以太网或PoE；协议、针脚、线缆及实际长度待核。紫色连接线只作路线示意。
