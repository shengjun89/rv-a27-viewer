# R7 驾驶舱与车顶出图层

打开“房车完整布局_R7_驾驶舱与车顶出图层.FCStd”。模型树末尾新增两个独立组：

- 驾驶舱细节｜出图参考・默认隐藏
- 车顶｜出图参考・默认隐藏

选中对应组，按空格开启/关闭。出图时按镜头需要开启，内饰工作时保持隐藏。保存后重开两组默认隐藏已核验；原1370对象的显示、位置与类型保留，原工程文件未覆盖。

驾驶舱增加仪表台、方向盘、中控、门内饰、踏板、前挡/侧窗与内后视镜等；车顶为原Blender屋顶/额头及既有顶部装备参考。43项为按显示材质合并的网格，不是43个采购件。使用原坐标，米转毫米；未重绘为加工实体，网格含开放或组合表面，不作封闭实体、承载或厂商尺寸依据。部分材质为适合CAD预览的简化显示。

本文件为R7基础的独立增量副本。没有回填网页E01R10逆变器、WC01坐便器、CR50冰箱等独立增量，不能称整车各版本完全同步。车头曲面纠正、完整驾驶舱外壳、键盘产品精模和正式分享图仍是另行工作。

网页底部“驾驶舱细节”“车顶”分别开关，默认关闭；首次开启才下载细节。查看其他功能分区时暂时隐藏，恢复整车保留先前选择。电路模式已开启的细节层同样为4%不透明度；关闭电路恢复原材质。
